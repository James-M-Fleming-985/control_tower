# Systems³ Landing Page

A beautiful, modern landing page for the Systems³ suite of business management tools.

## Features

- 🎨 Beautiful gradient design
- 📱 Fully responsive
- ⚡ Lightning fast (static HTML)
- 🎯 SEO optimized
- ✨ Smooth animations

## Products Showcased

1. **Project Reporter** - MS Project XML to Gantt charts and roadmaps
2. **Feedback Collector** - Customer feedback management system

## Deploy to Vercel

```bash
cd systems3-landing
vercel --prod
```

## Technologies

- HTML5
- Tailwind CSS (via CDN)
- Google Fonts (Inter)
- Vanilla JavaScript
