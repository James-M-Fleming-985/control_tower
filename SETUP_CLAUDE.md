# 🚀 Quick Setup for Claude Sonnet 4.5

## ✅ You're Ready to Use Claude Sonnet 4.5!

The build system is **pre-configured** to use **Claude Sonnet 4.5** by default.

---

## 🔑 Step 1: Set Your API Key

```bash
export ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

**To make it permanent**, add to your `~/.bashrc`:

```bash
echo 'export ANTHROPIC_API_KEY="sk-ant-your-key-here"' >> ~/.bashrc
source ~/.bashrc
```

---

## 🧪 Step 2: Verify Your Setup

```bash
# Check API key is set
echo $ANTHROPIC_API_KEY

# Should output your API key (not empty)
```

---

## 🎯 Step 3: Build Your First Feature!

```bash
# Build Workflow Orchestration Engine with Claude Sonnet 4.5
python build_feature.py "projects/PROJECT-003 TDD ENFORCER/SYSTEM-003-03 WORKFLOW ORCHESTRATION SYSTEM/FEATURE-003-03-01 Workflow Orchestration Engine/FEATURE-003-03-01_workflow_orchestration_engine.yaml"
```

That's it! Claude will automatically:
- Generate all tests
- Generate all implementations
- Run full TDD cycle (RED → GREEN → REFACTOR)
- Create verification reports
- Build all 3 layers sequentially

**Estimated time:** 30-60 minutes

---

## 🤖 Why Claude Sonnet 4.5?

The system uses **`claude-sonnet-4-5`** model (as defined in your AI Provider Abstraction):

```python
# From requirements_verification_complete.yaml, line 127
class: "AnthropicProvider"
model: "claude-sonnet-4-5"  # Default model
```

**Benefits:**
- ✅ Excellent code generation quality
- ✅ Strong reasoning for TDD cycles
- ✅ Good at following specifications
- ✅ 200K token context window
- ✅ Cost-effective for code generation

## 🐛 Troubleshooting

### "API key not set"

```bash
# Check if key is exported
echo $ANTHROPIC_API_KEY

# If empty, export it:
export ANTHROPIC_API_KEY="sk-ant-..."
```

### "Feature specification not found"

Use the **full path** to the YAML file:

```bash
python build_feature.py "projects/PROJECT-003 TDD ENFORCER/SYSTEM-003-03 WORKFLOW ORCHESTRATION SYSTEM/FEATURE-003-03-01 Workflow Orchestration Engine/FEATURE-003-03-01_workflow_orchestration_engine.yaml"
```

### Rate Limits

Claude has rate limits. If you hit them:
- Wait a few minutes
- The script will show the error
- Resume from where it left off
